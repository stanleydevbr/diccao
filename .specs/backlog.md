# Backlog do produto

## Priorização
### P0 - Essencial
1. Caderno de exercícios com listas e descrições.
2. Plano prático semanal automatizado.
3. Gravação e reprodução da voz do usuário.
4. Persistência local de registros e anotações.

### P1 - Importante
5. Ajuste de nível de treino por perfil.
6. Estatísticas simples de prática e progresso.
7. Destaque para exercícios de maior impacto.

### P2 - Futuro
8. Compartilhamento de trechos.
9. Feedback com IA para análise de fala.
10. Sincronização multi-dispositivo.

## Histórias de usuário
- Como iniciante, quero ver exercícios simples, para começar sem medo.
- Como usuário ocupado, quero um plano semanal curto, para manter a rotina.
- Como praticante, quero gravar minha voz, para ouvir e corrigir falhas.
- Como estudante, quero guardar meus treinos, para acompanhar evolução.
