# Features

## Feature 1 - Caderno de exercícios
- Seleção por foco: respiração, articulação, ritmo, entonação e expressão.
- Cada exercício tem descrição, objetivo e recomendação de tempo.

## Feature 2 - Plano prático
- Gera uma rotina semanal com 4 a 5 blocos de treino.
- Ajusta duração e intensidade conforme o nível do usuário.

## Feature 3 - Gravação de voz
- Botão de iniciar e encerrar gravação.
- Reprodução do áudio registrado.
- Lista local de gravações salvas.

## Feature 4 - Registro e feedback
- Campo para anotações do exercício.
- Guarda dados no navegador para manter histórico simples.

## Feature 5 - Expansão futura
- Sugestões de melhorias baseadas em performance diária.
- Exportação de histórico e relatórios simples.
